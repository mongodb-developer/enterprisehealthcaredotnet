# Brand fonts (not included)

The MongoDB brand typefaces are licensed and are not distributed with this sample.
If you are licensed to use them, place these files in this folder (they are gitignored):

- `Sohne-Regular.ttf`
- `SohneCondensed-Bold.ttf`
- `SohneMono-Medium.ttf`
- `MongoDBValueSerif-Regular.otf`

Without them the app falls back to system fonts and works as normal.
